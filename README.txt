FRESHMART - ANDROID GROCERY APP (JAVA)

HOW TO OPEN:
1. Extract FreshMart.zip.
2. Open Android Studio.
3. Choose File > Open and select the FreshMart folder.
4. Wait for Gradle sync to finish.
5. If prompted, install Android SDK Platform 35 and use JDK 17.
6. Create an Android emulator (Device Manager) or connect an Android phone with USB debugging.
7. Press the green Run button.

FEATURES:
- Grocery product listing
- Category filtering
- Product search
- Add to cart
- SQLite cart storage
- Increase/decrease quantities
- Automatic total calculation
- Checkout form
- Demo Cash on Delivery order confirmation
- Local SQLite order record

NOTES:
- This is an educational demo. It does not process real payments or send orders to a real store.
- Customer phone/address are validated in the checkout screen but are not stored in this starter version.
- Product images are represented by emoji to keep the project offline and easy to run.
